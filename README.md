# Rumo ao Planalto

Protótipo independente de jogo de estratégia eleitoral brasileiro, jogável no navegador (computador e celular).

## Como jogar

Abra o [index.html](./index.html) no navegador, ou configure o GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

- 6 candidaturas no 1º turno: você e 5 IAs.
- Em todo o Brasil, investimentos estaduais, regionais e nacionais.
- Vitória no primeiro turno com mais da metade dos votos válidos; caso contrário, os dois mais votados disputam o segundo turno.
- Brancos e nulos ficam fora dos votos válidos simulados.
- O jogo salva localmente a partida no navegador.

## Aviso

Simulação fictícia: não representa pesquisa eleitoral, estimativa real de voto, endosso político ou campanhas oficiais. O código é original e não utiliza o código proprietário do jogo 270. Fontes geográficas opcionais: [br-geojson (CC0/IBGE)](https://github.com/henriquemalvar/br-geojson). Referência das regras eleitorais: [TSE](https://www.tse.jus.br/comunicacao/noticias/2022/Outubro/entenda-como-e-eleito-o-presidente-da-republica).
